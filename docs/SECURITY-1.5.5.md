## 6. 后续独立验证与公开发布条件

1. **准备独立可信 Windows 环境。** 本机客体构建已完成，但不能将其等同于宿主或虚拟化层的可信证明，也不能在受感染宿主直接解压运行来补测试。
2. **不恢复污染输入。** 如需独立重建，只迁移经审查的源码 / 锁文件，重新获取并核验官方固定依赖；不复制旧 `node_modules`、缓存、隔离证据、旧归档 / ASAR 或旧输出。
3. **补齐 Windows 实际验证。** 原生 GUI、便携自解压、平台探测及五包安装器分别记录结果；3 个隔离包保持执行前拒绝，不因界面可见或按钮存在而恢复旧载荷。

6. **明确发布状态。** 当前为「本地隔离构建与归档交付完成；AV 告警未解除，Windows 原生验证未完成，宿主仍感染」，不是公开发布、全功能验收或已清毒。
